# Спрайты

Графика хранится как **SVG** в `js/sprites.js` и загружается в Canvas при старте.

## Анимации (`js/animations.js`)

| Анимация | Описание |
|----------|----------|
| Колёса | Вращение от скорости |
| Лицо мопса | Моргание, сон, жевание доширака |
| `police_0/1` | Мигалка ДПС (2 кадра) |
| `fuel_0/1/2` | Пульсация канистры (3 кадра) |
| `money_0/1` | Блёстки (2 кадра) |
| `cow_0/1` | Движение ног |
| `accident_0/1` | Дёрганье обломков |

## Файлы в атласе

| Ключ | Описание |
|------|----------|
| `truck_red` | Красная фура (дефолт) |
| `truck_blue` | Синяя (магазин) |
| `truck_gold` | Золотая (магазин) |
| `pothole`, `police`, `traffic`, `cow`, `accident`, `roadwork` | Препятствия |
| `fuel`, `money` | Пикапы |
| `tree`, `hill` | Фон |

## Заменить спрайт

1. Откройте `js/sprites.js`
2. Найдите константу, например `TRUCK_SVG` или `COW_SVG`
3. Отредактируйте SVG или вставьте свой (viewBox лучше сохранить)

Либо положите `sprites/truck.png` и в `SpriteAtlas._loadAll()` добавьте:

```javascript
this.images.truck_red = await loadImage('sprites/truck.png');
```

## Экспорт из Figma / Aseprite

Экспортируйте PNG 2x (например 280×320 для фуры) и подключите через `loadImage`.
